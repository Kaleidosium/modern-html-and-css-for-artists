The .flow Utility

Browser default margins go in both directions and collapse into each other unpredictably. A CSS reset strips them all. The .flow class then uses the "lobotomized owl" selector (* + *) to add vertical spacing back in a single direction of margin. The default value of 1em scales with each element's font size, so headings get more space than body text.
