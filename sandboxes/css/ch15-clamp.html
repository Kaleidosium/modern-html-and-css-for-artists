font-size: clamp(1.25rem, 4cqw + 0.5rem, 3rem);

The font size smoothly interpolates between the minimum (1.25rem) and maximum (3rem) as the container changes width. No breakpoints, no jumps.

This demo uses cqw (container query width) units so the text responds to the resizable box. In real projects, you'll choose between vw (viewport-relative) and cqw (container-relative) depending on whether the text should scale with the browser window or its parent component.
