# Modern HTML & CSS Guide for Artists

A craft-focused, two-part guide covering modern HTML and CSS fundamentals for artists and other creatives.

Websites are living documents rather than static canvases. This guide approaches web development through the lens of creative craft. Focusing on intentional structure, semantic markup, fluid design, and clean architecture.
